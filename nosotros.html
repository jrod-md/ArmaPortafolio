Nosotros

Por qué existe Folium81 y cómo fue construido.

Nuestra historia

Cada semestre, estudiantes de FISC pasan entre 3 y 6 horas armando su Portafolio Digital Estudiantil la noche antes de la entrega. El proceso es repetitivo, propenso a errores y no enseña nada. Folium81 existe para eliminar ese tiempo perdido y devolvérselo al estudiante.

Principios

Costo cero

Folium81 es y siempre será gratuito. Sin planes premium, sin publicidad, sin monetización de datos.

Privacidad por diseño

Ningún archivo se almacena. La arquitectura fue diseñada con la Ley 81 de Panamá como restricción, no como cumplimiento tardío.

Código abierto

Todo el código es público bajo licencia MIT. Puedes auditarlo, usarlo como referencia o contribuir.

Cómo está construido

Frontend
React + Vite, alojado en Cloudflare Pages
API
AWS Lambda (Python), sin servidores propios
Almacenamiento
Cloudflare R2 — archivos eliminados en 1 hora
Base de datos
AWS DynamoDB — solo tokens de sesión
Email
AWS SES — solo para enlaces de acceso
IA (opcional)
Groq API con modelo Gemma
Costo mensual
$0

Folium81 es software libre.

Si eres estudiante o docente de UTP y quieres contribuir, reportar un error o proponer mejoras, el repositorio está abierto.
