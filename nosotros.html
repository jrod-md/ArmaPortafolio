Nosotros

Por qué existe este proyecto y cómo ayuda a preparar el portafolio estudiantil.

Nuestra historia

Cada semestre, estudiantes de FISC invierten horas en ordenar su Portafolio Digital Estudiantil. Portafolio FISC nace para simplificar ese proceso, reducir errores de armado y permitir que el estudiante se concentre en revisar su contenido, no en construir la estructura manualmente.

Principios

Costo cero

Portafolio FISC es y siempre será gratuito. Sin planes premium, sin publicidad y sin monetización de datos.

Uso directo

El MVP se enfoca en abrir el generador, completar los datos y descargar un ZIP listo para entregar.

Código abierto

El código está disponible para revisión y mejora. La meta es que el funcionamiento sea auditable y fácil de entender.

Cómo está construido

Frontend
HTML, CSS y JavaScript modular
Acceso
Entrada directa al generador, sin cuenta ni correo
Generación del portafolio
Organización de carpetas, creación de portada PDF y armado del ZIP final
Descarga
Archivo ZIP listo para entregar al finalizar el asistente
Backend
Reservado para funciones auxiliares futuras
Estado actual
Aplicación estática enfocada en generar el paquete de entrega
Enfoque
Formato correcto, rapidez y entrega simple del portafolio

Portafolio FISC es software libre.

Si eres estudiante o docente de UTP y quieres contribuir, reportar un error o proponer mejoras, el repositorio está abierto.
