# Asset Notices

The `assets/` directory contains the runtime assets of the site.

## Runtime assets

- `assets/templates/portada_base.PNG` is loaded by `js/generate.js` as the base image for the generated cover PDF.
- `assets/fonts/LiberationSans-Regular.ttf` and `assets/fonts/LiberationSans-Bold.ttf` are loaded by `js/generate.js` and embedded in generated PDFs.

## Showcase screenshots

The files under `assets/showcase/` are user-supplied captures used by the landing page to show the generated cover and the final folder structure. They include sample-looking student and institutional information; verify that the values are synthetic or replace/redact them before sharing the site in a context where they are not intended to be public.
