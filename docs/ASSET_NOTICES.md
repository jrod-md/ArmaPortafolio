# Asset Notices

The `assets/` directory contains runtime assets and retained reference materials.

## Runtime assets

- `assets/templates/portada_base.PNG` is loaded by `js/generate.js` as the base image for the generated cover PDF.
- `assets/fonts/LiberationSans-Regular.ttf` and `assets/fonts/LiberationSans-Bold.ttf` are loaded by `js/generate.js` and embedded in generated PDFs.

## Reference assets

The files under `assets/logos/` are retained reference materials. They are not referenced by the current HTML or JavaScript workflow. Their names and visual content may be subject to third-party rights and are not covered by the application's MIT source-code license.

Do not treat these assets as original application code. Keep their provenance and usage scope separate from the implementation files.

## Showcase screenshots

The files under `assets/showcase/` are user-supplied captures used by the landing page to demonstrate the generator flow, generated cover, and final folder structure. They include sample-looking student and institutional information; verify that the values are synthetic or replace/redact them before sharing the site in a context where they are not intended to be public.
