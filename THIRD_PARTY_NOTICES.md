# Avisos De Terceros

Este proyecto incluye o referencia materiales de terceros. La licencia MIT de
este repositorio aplica únicamente al código fuente creado para Portafolio FISC,
salvo que un archivo indique otra cosa.

## Librerías Incluidas

### pdf-lib

- Fuente: https://github.com/Hopding/pdf-lib
- Licencia: MIT
- Uso: generación de PDF en el navegador.

### fontkit

- Fuente: https://github.com/foliojs/fontkit
- Licencia: MIT
- Uso: soporte para embeber fuentes en los PDF generados.

## Fuentes

### Liberation Sans

- Fuente: https://github.com/liberationfonts/liberation-fonts
- Licencia: SIL Open Font License 1.1
- Uso: renderizado de texto dentro del PDF generado.

### Inter

- Fuente: https://fonts.google.com/specimen/Inter
- Licencia: SIL Open Font License 1.1
- Uso: tipografía de interfaz cargada mediante Google Fonts.

### Lora

- Fuente: https://fonts.google.com/specimen/Lora
- Licencia: SIL Open Font License 1.1
- Uso: tipografía de títulos cargada mediante Google Fonts.

Consulta `assets/README.md` para el aviso específico de recursos.
